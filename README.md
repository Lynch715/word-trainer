# 单词拼写练习 · 四级 / 六级 / 雅思

看中文释义，补全被挖空的字母。纯前端单文件，离线可用（发音需联网）。

**在线体验：** https://Lynch715.github.io/word-trainer/

## 版本

当前 **v1.4.0**（2026-08-15）。版本号显示在页面标题右侧，手机上打开如果不是这个号，说明加载的是缓存，在网址后面加 `?v=140` 强制刷新。

## 功能

- **三套词库**：四级 1755 词、六级 1459 词、雅思 1130 词，均含词性与中文释义
- **三档难度**：随机挖空 25% / 45% / 70%，同一个词每次挖的位置都不同
- **真人发音**：调用有道词典录音，支持美音 / 英音切换，可关闭自动发音
- **提示与错词本**：可提示单个字母或直接看答案；答错自动进错词本，可单独重练
- **积分与段位**：按难度和连击给分，青铜到王者七级段位
- **成就系统**：16 枚成就徽章，含连续打卡、零失误、硬核挑战等
- **打卡热力图**：近 13 周练习记录可视化
- **四套皮肤**：深空蓝 / 暗夜青 / 暮紫 / 纸白，点头部调色盘切换，选择会被记住
- **成果图导出**：一键生成竖版战报，高度随内容自适应，跟随当前皮肤配色

学习数据保存在浏览器本地（localStorage），不上传任何服务器。

## 添加到手机桌面

用手机浏览器打开网址 → 分享 → 添加到主屏幕，即可像 App 一样全屏使用。
